# SplitEasy 0.8.0 · Windows 开发预览

MoonBit Native 原生桌面分账应用，支持人员/消费管理、平均与实际金额混合结算、本地账单与草稿、复制导出及配套 CLI。

下载 Portable.zip 完整解压运行，或使用 Setup.exe 当前用户安装。无需浏览器、MoonBit 或服务器。附带 SHA256 和原生程序的示例账单截图，程序未进行商业代码签名。

AI 解析采用后台请求、外发前确认、逐笔预览后确认。所有计算由 MoonBit 核心完成。自动验证覆盖本地模拟 HTTP 与原生 UI，**真实模型演示尚待配置，不能认定所有 AI 参赛验收完成**。

Windows CI 已验证核心、CLI、真实原生控件、模拟 HTTP/取消/超时、安装与卸载。用户 Windows 10/11 的 DPI、输入法和视觉体验仍待人工实测。此版本是预览，不宣称已通过赛事官方验收。

普通分账完全本地离线。API Key 不写入账单、草稿或发行包。开源许可与第三方声明随包保留。
