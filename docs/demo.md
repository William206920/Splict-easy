# 演示与用户验收

## 离线混合结算

1. 解压便携包或安装，断开网络并启动 SplitEasy.exe。
2. 点击混合示例，确认替换，查看晚餐平均 200 元、奶茶按实际金额 75 元。
3. 统一结算：净额依次 +148、+20、-58、-54、-56 元；转账四笔 58、56、34、20 元。
4. 复制结算单并粘贴到记事本；保存账单并重新打开；编辑消费后旧结果应失效。
5. 在实际金额表单尝试填错合计，保存按钮应不可用；更正后可保存。
6. 给有消费引用的人员改名，引用应同步；删除应被阻止。

## AI 演示

按 AI_DEMO.md 配置真实服务，输入 examples/free_mixed.txt。发送前确认、逐笔预览、确认后结算。另试缺付款人案例，必须阻断。尚未配置真实模型时只能展示模拟检查，不能称真实演示完成。
