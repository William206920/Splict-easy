# 在线账单追加与预览

适用于 GitHub Pages 与 Vercel 在线版。Windows 0.9.1 已发布程序的 AI 确认流程保持原样；本次共享合并函数由 MoonBit 实现，并进行双目标回归。

## 怎么记入已有账单

1. 打开“AI 记一笔”，只描述这次新增的消费，写清成员、付款人、金额与参与分摊者。当前账本的笔数和总额显示在输入框上方；旧账单不会自动随请求发送。
2. 同意外发并确认发送后，等待解析。原账单暂不改变。
3. 预览默认选择“追加到当前账单”。查看当前金额、本次金额、确认后总额，以及每笔付款与个人份额。
4. 点击“确认追加到账本”。例如原来 3 笔共 140 元，新增一笔 30 元，结果为 4 笔 170 元。需要重新开始时，主动选择“替换当前账单”并勾选替换确认。

文本/JSON 导入也使用同一预览，可手动选择追加；导入默认保留原先的替换意图，并增加明确确认保护。取消、解析失败、份额不符或存在歧义，都不会写入旧账本。

## 合并规则

- 姓名完全相同视为同一成员，原名单顺序不变，新成员依次追加；不同的人请使用不同姓名。
- 原有消费完整保留，新消费追加到末尾。新成员不会自动参与以前的消费。
- 平均分摊尾差仍按最终成员顺序处理；预览显示合并后的实际份额。实际金额份额不变。
- 完全一致的消费会提示可能重复，包括本批内部重复；不会静默删除。确为第二次相同消费时，可勾选核对后继续。描述、日期或参与结构不同的相似记录仍需人工辨别。
- 继续使用 Int64 整数分；合并后超过 200 人、5000 笔或金额总和溢出时，原子拒绝。可改选替换或取消。
- 预览期间账单版本变化会阻止提交；多标签页改动仍受现有草稿检查保护。确认一次后即消耗预览，重复点击不能重复记入。

## 界面调整

提高辅助文字和输入框的字号与对比度；AI 页增加步骤引导和当前账本提示；预览从整段文本改为金额影响、记入方式、逐笔消费与份额卡片。替换按钮使用风险色，重复记录与覆盖确认放在相关位置。手机预览只保留一层内容滚动，操作按钮保持可见。

本地 MoonBit JS 60 项、Node 网关/桥接 15 项、Native 类型检查通过。浏览器实际验证 140 + 30 = 170 元、新成员追加、重复记录阻断和替换确认；检查 390×844 手机预览。Windows Native 测试运行依赖 MSVC，云端结果与公网验收另行记录。
