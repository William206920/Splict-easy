# Windows 0.9.2

AI 解析确认后默认追加当前账本，同名成员合并；原记录、旧成员顺序和已打开文件路径保留。新增成员不会参与以前的消费。文本/JSON 导入默认替换，可在核对页勾选追加。文件打开仍是替换语义。

核对页展示当前、本次与确认后的消费笔数和金额，以及按最终成员顺序计算的逐笔份额。完全一致的消费需要单独确认；替换已有账本需要勾选替换确认，并保留未保存账本的保存提示。取消不会修改账本，过期预览、溢出、人数/笔数限制、歧义及重复点击受到校验。

桌面 AI 支持兼容 Chat Completions 的 HTTPS 服务。Kimi 示例：`https://api.moonshot.cn/v1`、`kimi-k2.6`、用户自己的 Key。Key 只保留在进程内存，发送前确认目标服务和数据外发，模型返回后再次核对。CLI 流程不变，一次解析一份输入文件；本次追加界面属于 GUI。共享 Kimi 仍仅在线服务持有密钥。

验证范围：新增原生测试覆盖保留旧记录、最终名单尾差、重复核对、替换确认、成员名单导入、过期预览与溢出恢复；Windows 集成使用本地模拟 HTTP 测试异步请求、预览取消和确认追加，并检查窄窗口控件。真实 Kimi 通过原生客户端调用及 Windows 10/11 人工 DPI/输入法验收尚未完成，不能由模拟 HTTP 或在线版调用替代。

发行由标签对应源码在 Windows CI 重建，只有原生测试、CLI/GUI、模拟 AI、安装卸载和截图检查通过后才上传文件。`SHA256SUMS.txt` 对应安装包与便携包。
