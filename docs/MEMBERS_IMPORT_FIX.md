# 0.9.1 成员页和导入修复

## 用户可见的修复

- “管理成员”从主页输入框的焦点跳转改为真实独立页面，侧栏同步高亮。
- 成员页可添加、改名、删除和清空输入，显示选中人员引用了多少笔消费。改名更新全部引用；存在关联消费时拒绝删除，原账单保持不变。
- 普通页面可以直接通过侧栏互相切换。消费编辑离开前确认放弃；AI 请求及待确认预览不会被导航绕过。
- 姓名输入、选中成员、待导入文本、AI 配置/文本在页面切换和窗口重排时保留。
- 导入说明放在编辑框旁边；窄窗口下移到编辑框下方，可以滚动阅读。支持载入文本示例、完整 JSON 示例和当前账单 JSON，只改变编辑框。
- 导入或确认 AI 账单替换当前账单前，询问保存、放弃或取消未保存更改。取消不覆盖当前账单。
- 带 UTF-8 BOM 的账单 JSON 可以读取，金额仍直接解析为 Int64 整数分，不经过浮点。

## 文本快速上手

每笔一行，金额单位是元：

```text
人：小明 小红 小刚
小明 90 晚餐
小红 30 奶茶 =小明:10 小红:20
小刚 20 车费 @小明 小刚
```

默认名单全员平均。`@` 表示只由列出的人平摊，`!` 表示排除列出的人后平摊，`=` 表示逐人实际金额。一笔只使用一种标记，实际份额合计必须等于实付总额。

JSON 请点击应用中的“JSON 示例”取得完整可编辑模板。`amount_cents` 的单位是整数分，`9000` 表示 90 元；其他字段和 equal/exact 两种模式的填法在应用中有说明。不要把“导出报表”的 JSON 直接作为账单导入。
